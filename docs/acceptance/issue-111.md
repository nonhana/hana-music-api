均复用当前profile，无共享产品接缝新增；默认组合保持，不宣称官方客户端身份。普通config的crypto/domain/ua/e_r/acceptGzip、冲突headers与受控Cookie大小写变体不再覆盖声明，会话/设备仍按次传递，兼容变化用major changeset说明，低层createRequest保持原合同。

本票55模块共56个请求动作：search_suggest的mobile与web分别固定目标，其余每模块一个。全部请求分支一次POST，没有多请求模块或完全纯本地模块；top_list的truthy idx是本地500拒绝分支（零请求/零token），不能用空动作集替代其id请求。没有开放动态路径，search_suggest的原拼接收敛为两个固定目标。

全部cache=none。两处明确状态写入为fm_trash（修改FM排除状态）与recommend_songs_dislike（记录不感兴趣并返回替换歌曲），write/never。personal_fm、personal_fm_mode、aidj_content_rcmd、homepage_block_page是获取连续推荐/刷新内容，声明read/never作为保守政策，避免重放改变推荐流；源码/离线材料不证明是否持久推进上游状态，mode/subMode不是已证实的账号设置写入。与基线相比仅收紧这四模块的连接前重试，不新增重放。recommend_songs是当日推荐读取，保持connect。

其余逐项核对用途：style_preference读取偏好并无设置输入；UGC详情/贡献计数/百科查询均只读；search_match发送本地歌曲元数据作匹配，仍为一次上游读取，并非本地零请求或上传。五个搜索模块（search_default/hot/match/multimatch/suggest）保留read重试，其他读取connect；cloudsearch、ugc_artist_search、top_list不因名称升级到read。旧URI规则仅核对上限，不用于新业务声明。read只有显式retryNonIdempotent才允许已连接失败重试（最多6次），connect仅连接前最多3次，429/503/499/504不重试。
