目标：模块只传本地动作与业务参数；模块、raw、注册共用 ResolvedRequest → RequestPlan → transport。Call 只拥有模块数据，ExecutionScope 拥有实际执行依赖和期限。
范围：五个切片依次完成；保持 352 模块、389 动作及 profile/目标/业务数据/返回合同。非目标：上游可用性、协议或身份变更、业务 Schema、ReadStore 重写、真实账号、发布和自动接力。
授权：实现、生成、离线测试、独立审查与工作区交付；无 commit/push/PR/关票/真实上游/发布授权。原计划 AC-18 的 plan-only 前提由本次指令替换，其余边界保留。

适用门禁：每片依计划 Verification；最终串行 `bun run types:modules:check` → `bun run verify` → `bun run verify:sdk` → `bun run verify:fixtures` → `bun run test:load:smoke` → `bun scripts/mutation-test.mts --all`。verify 包含 docs:build，SDK 包含 build:check 与同包 Node/Bun。fixtures 虽无修改仍按计划执行。无真实上游、soak 或远端 CI 门禁，计划明确列为非目标。无缺失凭据条件，依赖当前 Bun/Node/Chromium。
