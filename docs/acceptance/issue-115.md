## 固定基线分支与阶段

`tests/fixtures/requests/special-chains.json` 来自独立git archive中的旧生成client；`baseline-wire`真实命令已执行。源码、合成输入和独立解码对照，不是官方抓包。所有API实际POST/json；plain的具体method/响应与字节独立检查。默认API e_r=false，无x-aeapi。weapiPc为浏览器UA+PC Cookie；eapi为既有iPhone UA+PC Cookie；clientlog为既有iPhone UA+osx Cookie。plain没有显式UA或Cookie。

| 模块                  | 实际阶段与协议/响应                                                                                                                       | 语义/cache/retry                         |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| audio_match           | interface plain GET /api/music/audio/match，JSON                                                                                          | read/none/never                          |
| avatar_upload         | weapi imageAllocate → `https://nosup-hz1.127.net` plain POST bytes → eapi submit                                                          | upload/none/never                        |
| cloud                 | eapi check/allocate → needUpload时weapi songAllocate、`https://wanproxy.127.net` plain GET json、动态NOS plain POST bytes → eapi info/pub | 上传never；lookup read/connect；全部none |
| cloud_import          | eapi check/v2 → eapi import，使用检查songId                                                                                               | read/none/never；write/none/never        |
| image_upload_token    | weapi imageAllocate，仅返回凭证                                                                                                           | upload/none/never                        |
| inner_version         | 无上游，空动作                                                                                                                            | 无profile                                |
| login_qr_create       | 无上游，pc/web及本地二维码                                                                                                                | 无profile                                |
| playlist_cover_update | file分配/上传再weapi提交；imgId仅提交；双/无输入本地400                                                                                   | upload与write/none/never                 |
