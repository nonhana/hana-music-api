# 合入后复用 PR 验证

- 普通 master push 和创建版本 PR 的路由只有在实际合入的 PR、最终 head、成功的 verify 及汇总 job 记录的 Git tree 全部对应时，才跳过重复离线验证。plan 留下源 run 链接。
- 五个分片在检查前后记录 Git 状态。汇总 job 核对每个分片的初始指纹和测试报告，与自己的干净 checkout 一致才留下复用凭据。
- 未找到证据、tree 不同、失败或缺失的检查、API 错误都补跑完整 verify。发布候选及手动发布演练继续走原有检查和变异门禁。
- 用离线错误控制、远端回退演练和最终主分支运行核对两条路径。以 run 创建至完成的墙钟时间与 #135 合入后的 2:20 比较。
