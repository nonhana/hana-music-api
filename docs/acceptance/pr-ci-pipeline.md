# PR CI 提速验收

基于 master 分阶段推送到同一个 PR，保留每次 Actions run。此 PR 的验收对象是普通 PR 与 master 的离线验证；发布流程另行切换，不用真实发布或真实账号来测 PR 性能。

| 入口           | 通过条件                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 模块生成和检查 | 批量格式化后的 357 个文件内容不变；任一受控入口过期时返回非零。                                   |
| PR 离线回归    | 原 local、sdk、smoke 的文件和用例保留；全部分片通过且文件并集无遗漏和重复，缺失证据时总门禁失败。 |
| 包与质量检查   | 原严格包检查、Node/Bun、浏览器、负载、fixtures、双类型工程、生成合同、静态检查和文档构建均通过。  |
| 故障演练       | 手动 failure 模式下真实断言失败，总门禁红灯；失败输出和原生 JUnit 可从该分片的 artifact 下载。    |
| 性能           | 用远端 run 的创建至完成时间比较原流程、仅批处理、分片去重三个阶段；单次样本不作为长期 P50。       |
