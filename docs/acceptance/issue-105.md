## 本轮门禁与证据边界

按顺序执行 `bun run types:modules:generate`、`bun run verify`、`bun run verify:sdk`、`bun run verify:fixtures`、`bun run test:load:smoke`、`bun run test:load:soak`、`bun scripts/mutation-test.mts --all`。完整本地集合及 SDK 集合由 `tests/suites.ts` 选择；`--all` 覆盖 playlist-subscribe 三故障及共享请求内核相关的 shared-reads/upload 故障，不把其他两组的通过替代 AC-11。

真实登录/收藏 E1 不适用于本轮本票验收：原票明确默认不连接真实账号，本轮验证请求合同与兼容性，没有新增真实账号写入要求。缺少当次身份、token、目标和写入/恢复授权时，不执行真实写专项，也不将历史 E1 当成本轮通过。若后续明确将 E1 加为本票条件，必须另行取得当次条件并在缺失时标为阻塞。

匿名真实 live、独立 CI 上传故障演练和发布 preflight 不适用于本轮：本票端点为账号写操作，本轮不验证匿名业务、测试系统部署或发布流程；相应控制样本仍由完整本地集合执行。历史 PR 119 的结果不替代本次本地门禁；本轮不触发远端 workflow。

响应回放只证明返回合同；实例内存 fetcher 证明 SDK/HTTP 请求编排，loopback transport 证明 socket/取消/清理边界。它们均不声称网易云当前接受 token 或真实账号状态已改变。
