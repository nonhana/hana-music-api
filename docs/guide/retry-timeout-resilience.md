# 重试、超时与连接策略

## 完整期限与取消

API 默认总期限为 8 秒，从 Call 建立前的执行入口开始，包含身份初始化、出口许可、网络、全部重试和完整正文读取。响应头到达不会停止计时。
`timeoutMs: 0` 可在受信任 SDK 调用中关闭普通 API 超时；上传仍受 5 分钟总上限约束。

网页读取默认 8 秒。上传单阶段 60 秒，整个上传模块最多 5 分钟。SDK `config.signal` 和 HTTP 原始请求信号会中断同一执行链。错误状态分别为：取消 499、超时 504、其他传输失败 502。

总期限由 Call 管理，单个请求的预算由 request.ts 统一取剩余总期限与上传阶段上限的较小值。入口不再另外创建计时器；自定义 Effect 请求能力也接受同一预算。

共享读取的一个等待者取消只退出自己；最后一个等待者取消才中断上游。自定义 fetcher 必须遵守传入的 signal；库可释放自己的许可，但无法强制停止不合作的第三方 Promise。

## 重试

未知操作默认仅对明确尚未建立连接的错误最多尝试 3 次，例如 ECONNREFUSED、EAI_AGAIN、连接建立超时。已知写入、登录、轮询、批量、上传不自动重放。

明确读接口可通过现有 `retryNonIdempotent: true` 名称启用额外重试；这个兼容字段不会为已知写操作解除保护。仅读操作的模糊断连以及显式配置的业务状态码可重试。

```ts
await hana.lyric(
  { id: '347230' },
  {
    retry: {
      retryNonIdempotent: true,
      retries: 2,
      backoffMs: 300,
      maxBackoffMs: 2000,
      jitter: true,
      statusCodes: [502],
    },
  },
);
```

退避采用指数增长和可选抖动，总期限与取消覆盖退避等待。每次真正发送都重新争取出口许可。`close` 使用 `Connection: close`，重试使用新连接策略。

## 冷却与忙碌

所有默认 SDK 和 HTTP 路径共用进程级出口：在网最多 8 次，每 host 每秒 4 次、突发 8 次，每有效身份每秒 2 次、突发 4 次。API、网页与上传请求在并发或速率额度不足时最多等待 32 个、2 秒，超时返回 503。

transport 在收到 HTTP 429 响应头时立即建立 host 和身份冷却；业务 code 429 在正文解释后建立冷却。
Retry-After 可为秒或 HTTP 日期，限制为 1 秒至 5 分钟，无效时为 30 秒。两种来源都保留 429 和 Retry-After 响应字段。
当前请求不重试；后续请求在冷却内返回 429，轮换身份不能绕过 host 冷却。

这些是本地保护参数，不是网易云官方限额或不触发风控的保证。多进程部署需要在可信反向代理另设共享限流。
